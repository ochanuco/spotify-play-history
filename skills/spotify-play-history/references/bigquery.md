# BigQuery Schema

## Datasets
- `spotify_raw` (ingestion)
- `spotify` (modeled)

## Tables
### `spotify_raw.plays_raw`
Append-only. Partition by `DATE(ingested_at)`. Cluster by `played_at`, `track_id`.

Columns:
- `user_id` STRING
- `played_at` TIMESTAMP
- `track_id` STRING
- `track_name` STRING
- `artist_name` STRING
- `album_id` STRING
- `album_name` STRING
- `album_image_url` STRING
- `duration_ms` INT64
- `context_type` STRING
- `context_uri` STRING
- `ingested_at` TIMESTAMP
- `run_id` STRING

### `spotify_raw.state`
Single-row state table.

Columns:
- `key` STRING
- `value` STRING
- `updated_at` TIMESTAMP

Key usage:
- `key = 'last_played_at'`
- `value` = ISO8601 or epoch ms

### `spotify.plays`
Deduped fact table generated by Dataform.
